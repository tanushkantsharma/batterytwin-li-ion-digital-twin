# Assumptions and limitations

## What is measured vs simulated
| Result | Basis |
|---|---|
| A–E, numerical checks | Simulation of the synthetic reference cell (ECM, assumed R/C/thermal values, PyBaMM-derived OCV) |
| G1, F (synthetic) | Simulation; ground truth is known because the data were generated by the same model |
| G2 | Model-to-model: ECM fitted to PyBaMM SPMe output. Not experimental validation |
| H | PyBaMM SPMe + SEI simulation. Not experimental validation |
| G3, G4, thermal fit, F (NASA), SOH, RUL | Measured NASA PCoE data (third-party redistribution; see `data_sources.md`) |

No laboratory work was performed; no result in this repository is an experimental validation of
the PyBaMM aging model.

## Assumed values (no defensible data)
* Reference cell R0 = 20 mΩ, R1 = 10 mΩ, C1 = 3000 F, R2 = 15 mΩ, C2 = 40 000 F; m·cp = 69 J/K,
  hA = 0.053 W/K. Order-of-magnitude choices for a 5 Ah 21700 cell, used only as ground truth.
* Experiment D's Arrhenius activation energy Ea = 30 kJ/mol is assumed (sensitivity study only).
  Temperature-dependent parameters were **not** identified from data: all NASA cells used were tested
  at one ambient temperature (24 °C).

## ECM on NASA data
* **No OCV test exists** in the dataset; OCV is identified jointly with R/C from one charge (≈1.5 A)
  and one discharge (2 A). OCV and RC polarisation are only partially separable; the fitted OCV is a
  model artefact, not a measured OCV, and hysteresis is not modelled.
* SOC is defined relative to the measured 2 A discharge capacity of each cycle (SOC = 0 at the
  protocol cut-off), not to a low-rate thermodynamic capacity.
* Coarse sampling (≈ 18.7 s) means R0 absorbs fast polarisation; fitted R0 (100 mΩ, 1RC) is
  therefore between EIS Re (45 mΩ) and Re + Rct (114 mΩ). The first EIS measurement is after
  19 discharges, the fit uses discharges 1–2.
* Largest residuals (up to 0.4–0.9 V) occur in the end-of-discharge knee and in the post-cut-off
  relaxation, which a 1–2 RC model with a smooth OCV cannot represent. 2RC did not improve
  held-out error over 1RC (mean held-out discharge RMSE 83.0 vs 84.4 mV).
* Parameters fitted at cycle 1 degrade with aging (held-out discharge RMSE 117 mV at cycle 100,
  148 mV at cycle 150). In G4 per-cycle refitting, R1 reaches its upper bound (0.3 Ω) at cycle 161.

## State estimation
* Synthetic EKF results use a perfectly matched model structure except for the listed mismatches;
  real-data performance is much worse.
* NASA EKF: the reference SOC is coulomb counting from full charge with the measured cycle capacity
  — a reference definition, not independent ground truth. EKF voltage noise σ_v = 50 mV represents
  model error, not sensor noise. With cycle-1 R/OCV parameters the EKF reduced an initial SOC error
  on early cycles but not on aged cycles (100, 150), where resistance has grown.
* The [0, 1] SOC projection helps any estimator near full charge; NASA tests start mid-discharge
  (reference SOC ≤ 0.8) to avoid crediting the filter for this.

## Degradation (PyBaMM)
* Only SEI growth is modelled; lithium plating (important at low temperature / high rate), particle
  cracking and loss of active material are disabled. 10 °C results therefore underestimate aging.
* Isothermal at ambient: self-heating at 2C is ignored.
* Capacity fade over 500 cycles is < 1 % for all conditions — far less than the NASA cells' ~30 %.
  The two sources are different cells and protocols (the NASA chemistry is undocumented) and must
  not be compared directly.

## SOH and RUL
* Four cells from one test campaign; leave-one-cell-out gives only four test folds. Metrics will not
  transfer to other chemistries, protocols or temperatures.
* Features require a full CC-CV charge starting from a discharged state.
* RUL: only three cells reach the 1.4 Ah EOL threshold (B0007's minimum is 1.4005 Ah). With n = 3 no
  learned RUL model is justified; only per-cell empirical extrapolation baselines are reported.
  NASA capacity data show regeneration after rest periods, which neither baseline models.

## Not implemented (documented extensions)
CC-CV in the forward simulator; OCV hysteresis; temperature-dependent parameters identified from
data (needs multi-temperature datasets, e.g. other NASA batches or CALCE); UKF / dual
state-parameter estimation; MATLAB/Simulink models (not available in the build environment).
