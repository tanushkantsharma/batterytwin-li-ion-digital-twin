# Data sources

Access date for everything below: **2026-10-25**.

## 1. NASA PCoE Li-ion battery aging data (measured) — cells B0005, B0006, B0007, B0018

| Item | Value |
|---|---|
| Citation | B. Saha and K. Goebel (2007). *Battery Data Set*, NASA Prognostics Data Repository, NASA Ames Research Center, Moffett Field, CA. |
| Catalogue page | https://data.nasa.gov/dataset/li-ion-battery-aging-datasets (DASHLINK_133; landing page https://c3.nasa.gov/dashlink/resources/133/) |
| License / terms | The catalogue page lists **"License not specified"**. Raw files are therefore **not** committed to this repository. |
| Official archive tried | `https://phm-datasets.s3.amazonaws.com/NASA/5.+Battery+Data+Set.zip` — not reachable from the build environment. |
| Files actually used | `B0005.mat … B0018.mat` from the GitHub repository `anirudhkhatry/SOH-prediction-using-NASA-Dataset` (branch `master`), a third-party redistribution of the original MATLAB files. SHA-256 in `data/nasa_sha256.json`. **Not independently verified against the official archive** — `scripts/prepare_nasa_data.py` tries the official archive first and reports whether hashes match. |
| Cells | Commercial 18650 Li-ion, rated 2 Ah (per NASA). Chemistry is not stated on the catalogue page; it is not assumed here. |
| Test structure (from the files) | Repeated CC-CV charge / CC discharge / EIS at ambient 24 °C (`ambient_temperature` field). Charge: ≈1.5 A CC to ≈4.2 V, then CV until current ≈0. Discharge: ≈2.0 A CC. Measured voltage at end of the first discharge: B0005 2.59 V, B0006 2.35 V, B0007 2.11 V, B0018 2.41 V (`Voltage_measured`; the cells were discharged to different cut-offs). |
| EOL criterion | Experiments stopped at 30 % fade of rated capacity (2 Ah → 1.4 Ah), as stated on the NASA catalogue page. |
| Records | B0005/6/7: 170 charges, 168 discharges, 278 impedance; B0018: 134, 132, 53. |
| Signals & units | time [s], voltage [V], current [A], temperature [°C] (surface), capacity [Ah], EIS-fitted `Re`, `Rct` [Ω]. |
| Sampling | Discharge: median Δt ≈ 18.7 s (B0005–7), ≈ 9.4 s (B0018). Charge: ≈ 10.8 s (B0005–7), ≈ 3.05 s (B0018). |

### Preprocessing (`scripts/prepare_nasa_data.py`, `src/nasa_data.py`, `src/soh_ml.py`)
1. Load with `scipy.io.loadmat(simplify_cells=True)`; current sign flipped so discharge is positive.
2. Every discharge is paired with the immediately preceding charge record (`prev_charge_idx`).
3. Cells are **never pooled for fitting** in the ECM work; ECM parameters are fitted on B0005 only and
   other cells are used strictly as held-out tests. SOH learning uses leave-one-cell-out splits.
4. SOH records are dropped when the charge starts above 3.9 V (not from a discharged state): 2 records
   each for B0005–7 and 3 for B0018 (`results/metrics/SOH_dropped_records.csv`).
5. SOC convention for ECM work: SOC = 1 at end of CC-CV charge; SOC = 0 at the protocol cut-off of the
   2 A discharge; the cycle's coulombic efficiency is `η = Q_discharge / Ah_charged` (≈ 0.98).

## 2. PyBaMM parameter sets (model inputs, not measurements)

* PyBaMM 26.10.1.1 — Sulzer et al., *J. Open Research Software* 9 (2021) 14.
* `Chen2020`: LG M50 21700 (NMC811 / graphite–SiOx) — Chen et al., *J. Electrochem. Soc.* 167 (2020) 080534.
  Used for the synthetic reference cell OCV and for the SPMe comparison (G2).
* `OKane2022`: degradation-capable extension — O'Kane et al., *Phys. Chem. Chem. Phys.* 24 (2022) 7909.
  Used for experiment H.

## 3. Drive-cycle current profiles (excitation only)

`US06.csv` and `UDDS.csv` from the `pybamm-data` v1.0.2 release
(https://github.com/pybamm-team/pybamm-data/releases/tag/v1.0.2), downloaded by
`pybamm.DataLoader`. Both are current-vs-time traces (1 s, max 8.1 A); the UDDS file header credits
the SLIDE project (https://github.com/davidhowey/SLIDE). They are applied to the *synthetic* cell.

## 4. Synthetic data

All "true" SOC/voltage in G1, F (synthetic) and experiments A–E are generated by this repository's
ECM with the assumed parameters in `src/reference_cell.py`; G2 and H are PyBaMM simulations. They are
labelled as simulations in every figure title and metrics file name where relevant.
